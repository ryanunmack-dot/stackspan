Minimalist shoe starter kit

One budget A/B, one known everyday trainer when you’re ready, and a single optional foot tool. Not a closet full of SKUs. Shopping talk only — not medical advice.

Start here: Pick ASITVO or WHITIN for a cheap geometry try-on. Step up to Xero Prio when you want clearer sizing/returns. Add one tool (toe spacers, TheraFlow, or foot roller) only if it already fits your evening — shoes first, gadgets second.

How to use the kit

  1. Order A or B; check toe room on arrival — if it pinches, return; don’t “break in” crushed toes
  2. Wear short indoor or easy walks first; keep your old pair for long concrete days
  3. Optional: one tool session while seated — stop if anything feels wrong
  4. When geometry feels boring (not dramatic), consider Xero Prio or stick with the budget pair
